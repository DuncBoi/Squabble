# Squabble (Android Application)
**Author**: Duncan Greene

This was an application I developed in *Kotlin* on Android Studio using *Firebase* and *Heroku's* video conferencing API.

## Description
- The idea behind Squabble was to provide a space for users to debate politics. I implemented *Reddit-style* discussion forums with upvotes and downvotes, video conferencing with random users, push notifications, 2-factor authentication, etc.
- The code I wrote can be found in this folder: `/app/src/main`
- Peaked at around 1000 users before (understandably) getting removed from the Google Play Store for user content violations! (*sigh*)
